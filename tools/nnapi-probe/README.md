# NNAPI probe

A throwaway Android app that answers one question: can an ordinary app reach the Tensor TPU through the NNAPI delegate of the classic TensorFlow Lite runtime (LiteRT 2.x does not ship that delegate)? It runs the two test models from `tools/make_spike_model.py` (copy `app/src/main/assets/spike_conv*.tflite` from the camera app into its `assets`), on the CPU, then through NNAPI pinned to the phone's driver `google-edgetpu`, then with NNAPI's defaults, and logs timings and an output digest under the tag `NNAPIPROBE`. Build it with the camera app's Gradle wrapper (`../../gradlew -p . :app:assembleDebug` after copying the wrapper and `local.properties`), install, start `probe.nnapi/probe.MainActivity`, read `adb logcat -s NNAPIPROBE`. Results: `docs/ix-pipeline.md`.
