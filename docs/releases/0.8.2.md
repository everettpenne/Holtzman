# Holtzman 0.8.2 (pre-release)

Polish for the Liquid Glass experiment (Settings > Camera > Liquid Glass (experiment), off by default). With it off, nothing changes from 0.7.1.

- The bars above and below the picture are plain black, as on the iOS camera. The blurred wash of the scene that 0.8.1 put there is gone; it added nothing and lagged behind the picture.
- Glass now samples the picture only where controls overlap it (the controls sheet, the first-run tip, the zoom stops), and does less work per frame.

Checked on an emulator only (launch and main screen); unit tests pass. Not yet seen on the Pixel 10a: the real look, frame rate and heat.
